# Диагностика и ручная проверка

## Где смотреть

| Что | Где |
|---|---|
| Журнал плагина | `%LOCALAPPDATA%\KandoHaptics\Logs\KandoHaptics.log` (+ `.1.log`…`.3.log`) |
| Журнал плагина в Logi Plugin Service (Info+) | `%LOCALAPPDATA%\Logi\LogiPluginService\Logs\plugin_logs\KandoHaptics.log` |
| Ошибки загрузки плагинов | `%LOCALAPPDATA%\Logi\LogiPluginService\Logs\plugin_logs\_errors.log` |
| Haptic-события сервиса | `%LOCALAPPDATA%\Logi\LogiPluginService\Logs\messages\eventSources`, `...\Logs\testing\event_sources.txt` |
| Обнаружение Kando | `%APPDATA%\kando\ipc-info.json` |

Для подробностей включите `"logLevel": "Debug"` в settings.json — применяется без перезапуска.

## Частые ситуации

**В журнале «Kando не обнаружен».** Kando не запущен или ни разу не запускался. Плагин
проверяет файл с интервалом до 10 с и следит за ним — после запуска Kando подключится сам.

**«Kando недоступен на порту N».** `ipc-info.json` остался от прошлого сеанса Kando.
Это нормально: плагин повторяет попытки (1, 2, 4, 8, 10 с…) и перечитывает файл.

**«Неподдерживаемая версия Kando IPC API».** Kando обновился и сменил `apiVersion`. Плагин не
падает и продолжает ждать; нужна новая версия Kando Haptics.

**События приходят (видно в Debug), но вибрации нет.**
0. Самая частая причина — путь установки с кириллицей или другими не-ASCII символами.
   Если в журнале есть предупреждение «Плагин установлен в каталог с не-ASCII символами»,
   подключите плагин из `C:\ProgramData\KandoHaptics`
   (`build\build.ps1 -LinkTo C:\ProgramData\KandoHaptics`) и перезапустите Logi Options+.
   Подробности — в docs/INSTALLATION.md, раздел «Путь установки без кириллицы».
1. Убедитесь, что MX Master 4 отображается в Logi Options+ и тактильная отдача включена в
   настройках устройства, интенсивность не на минимуме.
2. Проверьте `_errors.log` и журнал плагина на ошибки `Logitech SDK`.
3. Проверьте, что в settings.json `enabled: true` и событие включено.
4. Назначьте на кнопку необязательную команду «Test Kando Haptic» — она играет эффект
   `selectButton` напрямую, минуя Kando.
5. Убедитесь, что не установлено две копии плагина с именем `KandoHaptics` (например,
   пакет и `.link` в `%LOCALAPPDATA%\Logi\LogiPluginService\Plugins`).

**Слишком много вибраций.** Увеличьте `navigationCooldownMs` (100–150), выключите
`hoverSubmenu` или переключите наведение на `subtle_collision`.

**Ощущается задержка.** Уменьшите `navigationCooldownMs` или выключите
`trailingHoverFeedback`. Обычное наведение не задерживается: отложенным бывает только
сигнал сектора, на котором курсор остановился во время быстрого движения.

**После перезапуска Logi Options+ вибрации пропали.** Плагин загружается заново вместе с
сервисом; в журнале должна появиться новая строка «Загрузка плагина». Если её нет —
смотрите `_errors.log`.

## Чек-лист ручной проверки на MX Master 4

Перед проверкой: `"logLevel": "Debug"`, журнал открыт в редакторе с автообновлением.

| № | Шаг | Ожидаемый результат | ✓ |
|---|---|---|---|
| 1 | Установить `KandoHaptics_1_0_0.lplug4` | В журнале «Загрузка плагина», «Зарегистрировано haptic-событий: 15» | |
| 2 | Запустить Logi Options+ и Kando | «Подключено к Kando IPC v2 … start-observing отправлен» | |
| 3 | Открыть круговое меню | Событие `openMenu → Played` | |
| 4 | Почувствовать отклик открытия | Один мягкий импульс (`damp_state_change`) | |
| 5 | Медленно вести курсор по секторам | Лёгкий щелчок на каждом новом секторе, повторов на месте нет | |
| 6 | Быстро провести по всем секторам | Не сплошная вибрация, а редкие щелчки (≤ 1 за 70 мс) и щелчок на секторе остановки | |
| 7 | Войти в подменю | Один отчётливый импульс (`sharp_state_change`), без второго щелчка от дочернего элемента | |
| 8 | Вернуться из подменю | Импульс `damp_collision`, отличимый от наведения | |
| 9 | Выполнить команду | Подтверждение `completed`, заметное, но короткое | |
| 10 | Закрыть меню без выбора | Нет вибрации (closeMenu выключен по умолчанию) | |
| 11 | Закрыть и снова запустить Kando | «Соединение с Kando потеряно/закрыто», затем «Порт Kando изменился» и новое подключение; вибрация работает | |
| 12 | Перезапустить Logi Options+ | Плагин загружается заново и подключается без действий пользователя | |
| 13 | Поставить `"enabled": false`, сохранить | «Настройки загружены: enabled=False»; меню больше не вибрирует. Вернуть `true` — вибрация снова есть | |
| 14 | Проверить работу без назначенных кнопок | В Logi Options+ ни одно действие Kando Haptics не назначено, но шаги 3–9 работают | |
| 15 | Поменять `hoverButton.waveform` на `damp_collision` | Без перезапуска щелчок становится заметнее | |
| 16 | Оставить ПК в простое 10 минут с закрытым Kando | Журнал не растёт быстрее строки за смену состояния; нагрузки на CPU нет | |
